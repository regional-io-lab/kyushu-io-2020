# 九州9県統合地域間産業連関表（令和2年/2020年推計版）

福岡・佐賀・長崎・熊本・大分・宮崎・鹿児島・山口・沖縄の9県を対象に、県間の財・サービス
移出入額（県間取引額）を独自に推計したデータです。熊本地震レジリエンス分析シリーズの
基礎データとして作成しました。

## データの説明

- **ファイル**：
  - `data/kyushu_io_2020_estimate.csv` — 長形式（部門コード・部門名・発・着・推計額・精度区分の6列、5,159行）
  - `data/kyushu_io_2020_estimate_full.xlsx` — 県別の元データ、推計過程、バグ修正記録、
    手法上の位置づけメモまで含む完全版ワークブック
- **単位**：百万円
- **部門数**：統合104部門（各県の元の部門分類を104部門に統一。詳細はxlsx内「前提・注記」シート）

## 対象県と年

9県すべて令和2年（2020年）ベースで統一していますが、**大分県のみ例外**です。大分県の
公式R2産業連関表は本稿作成時点（2026年）でまだ公表されていないため、平成27年（H27）表
をもとにGDP成長率を用いた簡易延長推計を行っています。この推計には既知の限界があり、
生産額合計／GDP比率が他8県のレンジ（1.65〜1.88倍）を上回る2.82倍となっています。詳細は
`method/methodology.md`を参照してください。大分県の公式R2表は2026年9月末に公表予定で、
公表後は本推計値との照合・検証を行う予定です。

## 推計方法

重力モデルによる初期配分とRAS法による収束を組み合わせた「グラビティ-RAS法」を用いて
推計しました。この手法は独自の急ごしらえではなく、山田光男・中京大学名誉教授が2013年に
発表した手法体系と同一のものです。手法の詳細、学術的な位置づけ、公益財団法人九州経済
調査協会（九経調）が公表している九州地域間産業連関表との違いについては、
`method/methodology.md`をご覧ください。

## データ品質に関する既知の経緯

開発過程で発見・修正した問題を透明性のため記録しています。

1. **長崎県のコード取り違えバグ（修正済み）**：長崎県は産業連関表で独自の連番コードを
   使用しており、総務省の標準3桁コードとは対応しません。97部門の機械展開処理で、この
   連番をそのまま標準コードとして扱ってしまっていたため、部門によっては修正前比100倍
   以上の変化が生じました。長崎の全104部門について名称ベースで再抽出・再計算し、修正
   済みです。
2. **佐賀・宮崎の単位変換漏れ（修正済み・影響範囲限定）**：参照用の一覧シート1枚に限り、
   佐賀（千円単位）・宮崎（万円単位）の百万円への変換が漏れていました。本体の推計結果
   （本リポジトリのCSV/xlsxのデータ）はこの影響を受けておらず、該当シートのみ修正済み
   です。

いずれも詳細な経緯は`data/kyushu_io_2020_estimate_full.xlsx`内の該当シート
（「重要_長崎データバグ修正記録」「重要_佐賀宮崎単位バグ修正記録」「重要_大分R2推計_
整合性チェック」）に記録しています。

## 利用上の注意

- 本データは独自推計であり、公的機関（経済産業省・各都道府県・九経調等）が公表する
  公式統計ではありません。
- 部門によっては、全県の移出合計と移入合計の間に構造的な不一致（電子デバイス部門で
  約9倍、自動車部品部門で約2.2倍の乖離）が残っています。これはこの分野の推計手法に
  共通する限界で、本データ特有の不備ではありませんが、分析に用いる際は部門ごとの
  精度区分（CSVの「精度区分」列）を確認の上でご利用ください。
- 大分県のデータは上記の通りH27ベースの簡易延長推計である点にご留意ください。
